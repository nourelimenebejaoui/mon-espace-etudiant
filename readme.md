# mon espace etudiant

## description
mon espace etudiant est un mini-site web personnel qui presente trois matieres etudiees durant l'annee.

## les matieres
- developpement Web
- programmation
- digital Skills

## Technologies utilisees
- HTML : structure du site
- CSS : design et mise en forme
- JavaScript : interaction avec le bouton pour afficher et cacher un message

## Fonctionnalites
- Presentation des trois matieres
- Bouton interactif pour afficher et cacher un message

## Organisation du projet
- `index.html` : structure de la page
- `assets/styles.css` : style du site
- `assets/scripts.js` : fonctionnalites JavaScript
- ` trace_ai.md` : promts ai
